# APICompat

浏览器端的模型接口兼容性探测器。单文件、零后端、零构建；读取目标站点的模型清单，再按协议逐格请求并导出结果。

## 工程范围

- 10 种协议：OpenAI Chat、Anthropic、Responses、Google 原生、Google OpenAI、DashScope、Azure、Ollama、Cohere、Custom。
- 11 种失败归因：区分 HTTP 错误、模型不存在、协议不支持、无渠道、超时、CORS 等问题。
- 多轮采样：每格采样 1–5 次，延迟取中位数，状态取众数。
- 测速档：首块成功后继续收流并记录输出速度；普通探测在首块成功后停止。
- 导出：HTML、Markdown、JSON、CSV，结果包含测试口径。
- 主题切换：浅色 / 深色两态。太阳和月亮是仓库内置 SVG mask，不依赖外部项目或远程资源。

## 关键判定

### 先解析响应，再认定成功

HTTP 200 不是成功标准。各协议分别解析自己的响应结构：

| 协议 | 成功判据 |
|---|---|
| OpenAI | `choices[]` 中解析出合法内容块 |
| Anthropic | `content[]` 或流式事件中解析出内容 |
| Google | `candidates[].content.parts[]` |
| Ollama | NDJSON 中的 `message` |
| Cohere | `content-delta` |
| Custom | 依次尝试已支持的响应结构 |

推理模型可能把 `max_tokens` 全部消耗在思考阶段，正文为空但响应合法。因此不能只用“正文非空”作为成功标准。

### 重试不能隐藏代价

只重试网络抖动、超时和 5xx；401、403、404、协议不支持等确定性失败不重试。重试成功的格子保留首次状态、首次耗时、退避等待和尝试次数，避免把长时间超时后成功伪装成快速成功。

### 并发要有上限

探测使用 6 条并发泳道，不使用无上限的 `Promise.all`。模型数和协议数增多时，瞬时并发可能让上游触发 429，得到的就不是有效兼容性结果。

### 主题状态与首屏

`data-theme` 只有 `light` / `dark` 两个值；首次加载且无用户选择时读取 `prefers-color-scheme`，之后把用户选择写入 `localStorage`。`<head>` 中同步落定主题，CSS 变量、`color-scheme` 和 `theme-color` 同步更新，避免首屏闪烁及原生控件颜色不一致。

主题图标位于 `assets/icons/theme-sun.svg` 和 `assets/icons/theme-moon.svg`，由 CSS mask 引用，颜色跟随 `currentColor`。按钮只保留图标本体，不使用外圈描边或圆底。

## 浏览器边界

API Key 不经过项目服务器，浏览器直接请求目标站点。代价是目标站点必须允许 CORS；mTLS、自定义 TCP、客户端证书等浏览器无法发出的请求不在范围内。

## 测试

`tests/mock.py` 使用 Python 标准库模拟 16 个模型 × 10 种协议，并覆盖声明与实测不一致、固定 404、间歇 500、流式逐字输出等情况。

```bash
# 启动 mock、运行 Playwright 断言并清理
bash tests/run.sh

# 手动运行
python3 tests/mock.py 8788 &
node tests/smoke.mjs
```

测试台为 **50 passed / 0 failed**。覆盖清单拉取、矩阵与统计、协议响应解析、重试代价、四种导出、390/768/1024px 溢出、`file://` 直开、两态主题、多轮采样和测速档。

## 工程笔记

### 1. 小 `max_tokens` 会误判推理模型

第一版把正文非空当成功，导致思考型模型被判失败。改为按协议解析合法分块，不依赖最终文本长度。

### 2. `nowrap` 会撑破移动端网格

协议路径使用单行省略号时，`max-content` 宽度会参与网格项的自动最小尺寸，390px 页面出现横向溢出。容器改用 `minmax(0, 1fr)`，并允许路径必要时换行。

### 3. 不存在的接口可能返回首页 HTML

只看状态码会把 `200 + HTML` 当成模型清单。解析前识别 HTML 正文，并归为“返回页面而非接口”。

### 4. 主题断言必须等待过渡结束

主题切换有背景与图标过渡，点击后立即读取样式会采到中间帧并误报白块。测试等待过渡结束后再检查终态。

### 5. DOM 改动后断言也要跟着改

重试标记的提示移动到外层单元格后，旧断言继续读取标记自身的 `title` 会得到空值。断言应定位当前语义归属节点，而非依赖旧 DOM 层级。

### 6. 位图转 mask 要区分 bool 与 uint8

`potrace` 将暗像素当作前景，而 alpha mask 通常以亮像素表示前景，需要先转 bool 再用 `~` 取反。对 0/1 的 uint8 直接调用 `np.invert` 会得到 254/255，结果可能变成整块画布或空路径，且不会抛异常。

## 限制

- CORS 失败与网络不可达在浏览器侧可能表现相同。
- 延迟是当前网络路径下的端到端首块时间，不等于服务器内部耗时。
- 矩阵只代表本次测试；渠道、额度和模型状态会变化。
- 多轮采样会按采样次数成倍增加请求数。
- 项目不保存历史结果；趋势对比需导出 JSON 留存。
